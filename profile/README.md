# LumaSoft

**LumaSoft (LUMA sp. z o.o.) is an independent Polish software company that builds AI tools for
database professionals under the SqlSage brand.** Our tools run inside the applications you already
use — SQL Server Management Studio and DBeaver — on your own Claude or ChatGPT account, with no API
key. Reads run automatically; writes and DDL stop for your explicit confirmation. Schema and SQL go
to the model; your query results do not, unless you opt in. Every AI action is written to a local
audit log on your machine.

We are based in Warszawa, Poland, and we build with the same engineering discipline we would want in
a database tool ourselves: deterministic checks over guesses, safety on by default, and honesty about
what a tool can and cannot do.

## Products (SqlSage brand)

- **SqlSage for SSMS** — an AI pair-DBA extension (VSIX add-in) for SQL Server Management Studio 22 on
  Windows. Explains errors, tunes slow queries and runs SQL safely.
  → https://sqlsage.lumasoft.org
- **SqlSage for DBeaver** — an AI SQL copilot inside DBeaver: query your database in plain language
  across PostgreSQL, MySQL/MariaDB, Oracle, SQL Server and SQLite.
  → https://sqlsagedbeaver.lumasoft.org

## What our tools share

- **Keyless** — they run on the Claude or ChatGPT account you already pay for. No separate API key,
  no metered second AI bill.
- **Safe by default** — read-only by default; a SQL classifier stops writes and DDL for your
  confirmation before anything runs.
- **Private** — schema and SQL are sent to the model; your data (query results) is not, unless you
  opt in per session.
- **Accountable** — a local audit log records every AI action on your machine.
